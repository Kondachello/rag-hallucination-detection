# Полный просмотрщик спанов

Эта папка содержит автономную сборку визуального аудита HalluGraph и GraphEval на
RAGTruth. Она предназначена для показа результатов коллегам и ручного разбора всех
обработанных примеров.

## Быстрый запуск

Откройте `index.html` двойным щелчком. Интернет, сервер и повторный запуск языковой
модели не требуются: данные уже встроены в страницу.

Если браузер не разрешает открыть локальный HTML, выполните из этой папки:

```powershell
python -m http.server 8000
```

После этого откройте <http://127.0.0.1:8000/>.

## Что находится на странице

- Общие метрики рассчитаны по полному архиву из 749 ответов.
- В просмотрщик включены все 749 ответов из сохранённого парного запуска.
- Справа расположены поиск, фильтры, сортировка и список примеров.
- Выбранный пример открывается сразу на вкладке `Спаны`.
- Выбор примера и вкладки сохраняется в адресе после `#`; такую ссылку можно
  скопировать и передать коллеге.

## Как читать подсветку

- красная нижняя линия — эталонный спан галлюцинации RAGTruth;
- синий фон — спан HalluGraph;
- оранжевый фон — спан GraphEval;
- фиолетовый фон — участок, выделенный обоими методами.

Красная линия остаётся видимой поверх фоновой подсветки. Благодаря этому можно
сразу увидеть как попадание метода в эталон, так и лишнюю подсветку.

## На что смотреть

1. Найдите пример по идентификатору или тексту либо используйте фильтр и сортировку.
2. На вкладке `Спаны` сравните подсветку методов с красной линией RAGTruth.
3. В таблице под ответом посмотрите точные координаты, риск, число общих символов
   с эталоном и связанную графовую единицу.
4. На вкладке `Метрики` сравните IoU, точность, полноту и лишнюю подсветку.
5. На вкладках HalluGraph и GraphEval проверьте граф и долю уникальных графовых
   единиц, которые удалось найти в тексте ответа.

## Важные ограничения

- Эталонная разметка присоединяется только после завершения работы детекторов и не
  является их входом.
- Спаны строятся консервативным поиском текстовых упоминаний: точное совпадение,
  совпадение без учёта регистра и совпадение с нормализованными пробелами.
- Это не семантический поиск перефразирований. Если графовая сущность выражена в
  ответе другими словами, сопоставление может её пропустить.
- Для HalluGraph в архиве нет непрерывного риска каждой отдельной единицы, поэтому
  его локализация остаётся бинарной.
- Сортировка по IoU использует эталон и предназначена только для анализа, а не для
  работы детектора на новых данных.

## Состав папки

- `index.html` — автономный интерактивный просмотрщик;
- `dataset-metrics.json` — общие метрики полного расчёта;
- `span-localization-manifest.json` — происхождение данных и параметры анализа.

## Как пересобрать

Команда выполняется из корня репозитория и использует уже сохранённый архив:

```powershell
python scripts/build_span_localization_audit.py `
  --archive-dir outputs/datasphere-results/zhenya-750all-final/zhenya-750all-20260726-165854/historical-cache-replay `
  --responses outputs/datasphere-results/zhenya-750all-final/source/response.jsonl `
  --output-dir span_viewer_demo `
  --viewer-only `
  --viewer-file-name index.html
```

Команда не вызывает LLM, HalluGraph, GraphEval, KGGen или DataSphere. Она только
читает запечатанные локальные результаты и повторно строит отчёт.
