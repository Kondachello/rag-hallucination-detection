# Опыт с малыми MLP/FFN

Запуск: `run_mlp_experiment.ipynb`, «Выполнить все». Готовый кэш используется
обязательно, кодировщик не загружается. Подходит CPU или T4.

## Зафиксированные комбинации

31 метод: 27 нейросетевых и 4 линейных контроля.

- 12 комбинаций: общий/общий с типом/раздельный FFN × до/после пула × среднее/максимум.
- 3 блока без признаков подтверждённости.
- 3 блока с выходом 16 вместо 32.
- 3 блока с GELU вместо ReLU.
- 2 блока на исходных 4096 координатах после среднего, без PCA.
- MLP только на 9 признаках.
- Общий FFN только для E/R/C и только для ответа: 2 варианта.
- Общий блок без нелинейности: контроль полезности ReLU.
- Логрег на признаках, E/R/C, ответе и всех четырёх векторах: 4 контроля.

Основной блок PCA128→256→32, тип добавляет 8 обучаемых координат.
Для четырёх отдельных блоков преобразование своё для каждого типа.
Сырые векторы используют 4096→256→32, без огромного расширения.
К выходам добавляются 9 доступных признаков; линейная голова с sigmoid
обучается одновременно с FFN. Признаки не заполняются выдуманными проверками
отношений. Пустые типы обнуляются после FFN. Статусы компонентов в FFN не подаются.

## Обучение

Общая PCA обучается на средних векторах непустых типов обучающих ответов;
не на всех компонентах, чтобы длинные ответы не получали больший вес.
Каждая внешняя часть имеет своё преобразование. Для внутреннего выбора
числа эпох/C PCA обучается заново только на внутреннем обучении.

Внешние части: прежние групповые 5×3 на 629 ответах.
Внутри каждой обучающей части одна из пяти групповых частей выбирает
число эпох по log_loss и регуляризацию логрега из .01/.1/1.
Затем сеть заново обучается на всей обучающей части выбранное число эпох.
100 эпох максимум, ожидание 10 эпох без улучшения, AdamW .001,
регуляризация .01, отключение 20% нейронов, пакет 32, градиент ограничен 5.
Два начальных состояния: 11 и 29 с добавлением номера внешней части.
Для общей оценки усредняются вероятности; разброс инициализации также сохранён.

121 отложенный ответ уже просмотрен в прошлом опыте. Это дополнительная,
не независимая подтверждающая проверка. Перебор 31 метода является разведочным;
нового победителя следует проверить на новых ответах.

## Контроли и интерпретация

LR_Q_ALL получает ровно те же четыре стандартизированных PCA128-вектора,
что основные FFN. Так сравнивается обучаемое преобразование, а не только
добавление вектора ответа. MLP_Q отделяет нелинейность признаков от семантики.
Новый LR_Q_MEAN/ANSWER использует PCA128, старые модели использовали PCA8;
сравнения с прежней таблицей напрямую не интерпретируются как смена архитектуры.

Сохраняются ROC-AUC, PR-AUC (средняя точность), log_loss и F1 при пороге .5;
стандартное отклонение по частям, повторам и начальным состояниям.
Парные интервалы отложенной разницы строятся с пересэмплированием групп.

## Проверки и воспроизводимость

Кэш проверяется по SHA256, модели и данным. Размерности и один шаг всех
архитектур проверяются локально; полный опыт остаётся для Colab.
Завершённые обучения сохраняются в `artifacts_mlp/progress/` и повторно
используются только при совпадении подписи кода, протокола и данных.
В ZIP входят истории, прогнозы, метрики, код, данные, финальные веса и
преобразования. 219 МиБ эмбеддингов повторно не включаются: они доступны в GitHub.
