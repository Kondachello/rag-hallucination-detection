# Опыт 2: векторы компонентов в Google Colab

Эта папка самодостаточна: шесть файлов исходных данных, код проверки и расчёта,
набор моделей и ноутбук `run_experiment.ipynb`. При запуске нужен интернет только
для установки библиотек и первого получения закреплённой модели с Hugging Face.
Полный эксперимент локально при подготовке папки **не запускался**; таблица
метрик заполняется после выполнения ноутбука в Colab.

## Выбор текстовой модели

`BAAI/bge-small-en-v1.5`, ревизия
`5c38ec7c405ec4b44b94cc5a9bb96e735b38267a`. Это англоязычный
кодировщик семейства BERT: 384 координаты, предел 512 токенов. Он даёт
векторы отдельных токенов для сущностей/предикатов и вектор первого токена
для целого утверждения. Модель заморожена. Один кодировщик для всех вариантов
не смешивает эффект способа объединения с эффектом смены модели.

Источник: [карточка BGE-small](https://huggingface.co/BAAI/bge-small-en-v1.5),
[закреплённая ревизия](https://huggingface.co/BAAI/bge-small-en-v1.5/commit/5c38ec7c405ec4b44b94cc5a9bb96e735b38267a).
Этот выбор заменяет локальный `bert-base-uncased` в письменном `DESIGN_V1.md`
по новому запросу пользователя: более компактный кодировщик удобнее для
Colab и соответствует двум нужным видам вектора. Новая модель не обучается на
100 целевых метках.

## Кодирование компонентов

- `entity`: полный исходный ответ, среднее по токенам точного символьного
  интервала сущности. У пяти сущностей нет интервала — отдельно кодируется имя.
- `relation`: пара «полный ответ; направленная тройка», среднее **по токенам
  предиката во второй части**. Позиция второй части отслеживается отдельно.
- `claim`: самостоятельный текст утверждения, первый служебный токен.
- В варианте `B_triples` сущности берутся из названий концов троек, а
  отношения — из предиката тройки без полного ответа. У 65 сущностей нет
  точного совпадения с концом тройки; для них отдельно кодируется имя.

Усечение текстов запрещено: превышение 512 токенов и отсутствие токенов
на заявленном интервале останавливают расчёт. Векторы нормируются по длине;
результаты и точные позиции токенов сохраняются в `artifacts/`.

## Сравнение

Пять заранее определённых частей; для каждого ответа прогноз получается
только моделью, не обучавшейся на его метке. Метод главных компонент и
стандартизация подгоняются заново на обучающих ответах. Для линейных моделей
сила регуляризации выбирается внутренним трёхчастным разделением;
нейросети выбирают число эпох по внутренней проверочной части и затем
обучаются заново на всех 80 обучающих ответах. Порог F1 фиксирован как 0.5.

Основное сравнение — `M0` (13 признаков + средние E/R/C) против `A`
(только 13 признаков). Кроме него есть частота класса `P0`, локальный
HalluGraph, векторы без оценок, вариант троек, все `M1`–`M14` из банка
гипотез и исключение отдельных типов компонентов. `M14` дан двумя способами:
общий вектор ответа с оценками и с оценками плюс E/R/C. Всего 30 строк.

Таблица содержит среднюю логарифмическую потерю, площадь под ROC-кривой,
площадь под кривой точность–полнота, F1 и покрытие. Для исходного риска
HalluGraph логарифмическая потеря оставлена пустой: это не калиброванная
вероятность; рядом есть его калиброванный вариант. Для `M0−A` вычисляется
парный разведочный интервал. Имена методов и промежуточные настройки
сохраняются в `artifacts/` вместе с отдельными прогнозами.

Все 100 меток ответа выставлены GPT-4o; набор искусственно сбалансирован.
Местный строгий HalluGraph нужно будет сверить с обещанным отчётом.
Его оценки на старом архиве из 749 других ответов нельзя напрямую сравнивать
с этой сотней.

## Локальная проверка без обучения

Из этой папки:

```powershell
python smoke_test.py
```

Дополнительно можно указать путь к уже скачанному **быстрому**
BERT-токенизатору: `--tokenizer-dir PATH`. Тогда все позиции будут проверены
на нём без скачивания BGE. Ноутбук повторяет проверку на настоящем
токенизаторе BGE и не продолжит работу при несоответствии.

## Запуск в Colab

Опубликуйте **только эту папку** в доступной ветке GitHub и откройте
`run_experiment.ipynb` через вкладку GitHub в Colab. В первой исполняемой
ячейке укажите адрес своего репозитория и имя ветки; ячейка сама клонирует
репозиторий в Colab. Выберите среду с GPU, затем «Среда выполнения →
Выполнить все». После загрузки BGE ноутбук покажет примеры точных входов,
размерности и ход вычисления; последняя ячейка покажет и сохранит таблицу.
Если среда перезапустится, промежуточный кэш `artifacts/` исчезнет и векторы
придётся получить вновь, если их не скачать вручную.
